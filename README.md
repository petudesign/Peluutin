# Peluutin
A user-friendly web app for tracking substitutions, playing time, formations, goals, and match history in junior football.

## Development

```bash
cd app
npm install
npm run dev
```

## Deploying to Vercel

Import this repository in Vercel and set **Root Directory** to `app`. Vercel will detect the Vite project automatically.

Team, player, and match data is stored locally in the user's browser. The current MVP does not use a backend or synchronize data between devices.
